# CEDA Innovation Portal — user manual

**Service:** https://ohprime-ceda-portal.up.railway.app  
**Edition:** Hackathon prototype, 23 November 2026

## 1. Access and accounts

Open the service in a current desktop or mobile browser. A visitor can read the programme information and use the public Ask CEDA guidance assistant. To submit an idea, choose the account or sign-in action and register as an applicant. Enter the requested contact details and create a password. Applicant sign-in uses email and password in the current hackathon deployment. Staff receive an invitation from an administrator. In the hackathon deployment, the master and evaluator/adjudicator-only accounts sign in with a password; other staff accounts also use an authenticator app. Keep passwords and any authenticator codes private.

If account recovery is needed, use the recovery link on the sign-in screen and follow the available verified channel. Delivery depends on the configured provider. Contact a programme administrator if a code does not arrive.

## 2. Applicant: create and track an idea

1. Sign in and open the applicant dashboard.
2. Start a new idea. Choose the relevant programme, business category and business stage.
3. Complete the form steps. Required questions are marked. Questions vary with the chosen category and stage.
4. Save the draft as you work. Use **Continue draft** from the Drafts area to resume.
5. Add any requested supporting documents. Use the review step to check answers and funding figures before final submission.
6. Submit. Record the application reference. The submitted version is read-only; its stage and next action appear on the dashboard.
7. Check the portal notifications and application history for updates. If a reviewer requests more information, open that request, provide the response and submit it in the portal.

Do not assume that completing required fields means CEDA has approved or verified the idea. The portal checks completeness before review.

## 3. Evaluator: assess an assigned idea

Sign in with the evaluator account. Open **My Evaluations** or the assigned review queue. Select an assignment, read the applicant's answers and authorised attachments, then score each criterion in the assigned template. Save work before submitting. Submitted assessments are a record of the evaluator's independent judgment. Where clarification is needed, use the information request action. AI summaries, if available, are reading aids; the evaluator remains responsible for checking the original submission and the score.

## 4. Adjudicator: record a decision

Open **My Adjudications** and select the assigned case. Read the original submission and completed evaluator findings. Record scores, decision and rationale in the decision workspace. Save a draft if needed. Review the rationale before submitting because the final record is read-only.

## 5. Programme manager and administrator

Use the staff navigation to review applications, assignments and reports. Authorised managers can manage programme forms, category mappings, evaluation criteria and published guidance. Publish revised forms or criteria as new versions; existing records retain the version used when they were created. Administrators manage staff invitations, roles and programme access. Awarded stories appear publicly only after an authorised publication action.

## 6. Help and limits

Ask CEDA answers from approved guidance. It is not currently a live consultant chat. If an answer is unsupported, contact CEDA through its published contact channel. The prototype needs operational provider setup and acceptance testing before unrestricted public use. Never upload identity documents or real confidential ideas to demonstration accounts.
