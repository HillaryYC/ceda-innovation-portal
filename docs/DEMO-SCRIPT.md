# CEDA Innovation Portal — walkthrough and judging demo

Target a **4–5 minute video**. For the Top 5 presentation, the brief allows up to **10 minutes including Q&A**. Use prepared demonstration accounts and non-sensitive sample data. Start recording with the browser address visible.

| Time | Show | Narration point |
| --- | --- | --- |
| 0:00–0:25 | Public site and solution URL | One portal connects idea submission, review, decision and recognition. |
| 0:25–1:20 | Applicant registration/sign-in, dashboard, new draft and relevant form steps | Required fields, category/stage questions, draft saving and clear next action. Explain that live applicant SMS challenge is disabled for this hackathon stage. |
| 1:20–1:50 | Submit a prepared draft; show reference, status and notifications | The submitted record is traceable and cannot be casually overwritten. |
| 1:50–2:35 | Administrator's applications, allocation and criteria/templates | Roles and programme permissions, configurable forms and criteria, and reviewer assignment. If the queue worker is not live, use a preassigned sample and say so. |
| 2:35–3:15 | Evaluator workstation | Read evidence, score against criteria, save and submit an independent assessment; show request for more information and applicant response if prepared. |
| 3:15–3:50 | Adjudicator workstation | Compare submitted evaluator findings, record a reasoned decision and show that evaluator drafts remain private. |
| 3:50–4:20 | Reports, audit/activity history and awarded showcase | Participation and outcome visibility, traceable actions and controlled publication. |
| 4:20–4:50 | Phone-width view, architecture slide and conclusion | Responsive use; React/TypeScript, Laravel and PostgreSQL on Railway; versioned forms and criteria; server-enforced access. |

## Recording checks

- Rehearse every click once on the deployed URL. Keep backup prepared records so the demo does not depend on SMS, email, AI or background jobs.
- Hide browser bookmarks, secrets, private records and personally identifying information.
- Show actual results after each important action. Avoid calling the guidance assistant a live human consultant.
- End with one sentence on the remaining operational setup: provider delivery, workers, backups and live chat integration.
